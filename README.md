# 空间透镜（FolderLens）

在浏览器中查看文件夹容量、目录层级和空间分布。一个 HTML 文件，双击即可使用；无需安装、运行服务或联网。

当前版本：**1.2.0**。

## 开始使用

1. 下载本项目并解压，或单独保存 `FolderLens.html`。
2. 用桌面版 **Chrome 或 Edge** 打开 `FolderLens.html`。
3. 点击“选择文件夹”，授权读取要分析的目录。接口不可用时可使用“兼容选择”。

想先了解界面，可使用内置示例；示例是合成数据，不会扫描你的电脑。

## 可以查看什么

- 文件逻辑大小合计、文件数、子目录数和最大目录深度。
- 可逐层展开的目录树、空间分布、大文件排行和扩展名汇总。
- 各目录层级的数量分布，以及按层级、深目录筛选的结果。
- 名称搜索、当前目录或跨层级浏览，以及路径复制。
- 当前结果、完整文件清单、层级统计和待清理候选的 CSV 导出。

所选根目录的层级为 **0**，它的直接子目录为 **1**。最大目录深度只看目录，不把文件多算成一层；层级统计按条目的相对路径深度分组，根下文件与直接子目录同属第 **1** 层，每层容量只计该层文件，不叠加后代。停止扫描、读取失败或达到限制时，显示的深度和容量只反映已发现、已读取的部分。

“待清理”只记录候选，不执行删除、回收、重命名或写入。父目录及其后代同时选中时，会合并父子项；清单合计不代表实际可释放空间。

## 统计范围与限制

| 项目 | 口径 |
| --- | --- |
| 容量 | 文件逻辑大小合计；1 KiB = 1,024 B。不是磁盘实际分配空间，不做硬链接去重。 |
| 标准选择 | 遍历浏览器授权并返回的目录项，可以发现返回的空目录。 |
| 兼容选择 | 根据浏览器交付的文件清单推断目录，无法列出空目录或核验未交付项。 |
| 单次限制 | 最多 300,000 个条目；目录深度上限 128 层；单次元数据等待超时 20 秒。 |
| 扫描结果 | 可停止并查看部分结果；不是原子快照，文件变化后需重新扫描。 |
| 路径 | 浏览器不提供盘符绝对路径。手动补充根路径仅用于复制和导出，不核验真实磁盘位置。 |

系统目录、受限目录、符号链接、网络盘和云盘的覆盖及响应受浏览器、操作系统与存储服务影响。兼容选择准备文件清单期间，页面无法显示该阶段进度。云盘客户端也可能在元数据请求时产生额外动作。

## 隐私

- 只读取名称、相对路径、文件长度和文件修改时间，不调用读取文件正文的接口。
- 页面没有上传、遥测、远程脚本或远程字体；内容安全策略禁止网络连接。
- 扫描结果、目录句柄、候选清单和手动根路径仅保存在本次页面内存中；刷新或关闭后不恢复。浏览器本地存储只保存主题偏好。
- 导出的 CSV 可能包含敏感名称和路径。不要把真实扫描结果、真实目录截图、凭据或 `.env` 提交到 GitHub。

## 开发与检查

日常使用只需要浏览器。运行开发检查需要 **Node.js 20 或更新版本**，不需要安装 npm 依赖：

```sh
npm test
npm run check
```

测试使用合成目录和模拟接口，检查统计、层级、部分结果及导出等行为。静态检查用于核对单文件结构与内容安全策略。这些检查不能替代真实浏览器的目录选择授权、Windows 文件系统兼容性或安全软件验收。

修改内联脚本后，执行 `npm run update:csp` 更新 HTML 的内容安全策略脚本摘要，再重新运行上述检查。请保持单 HTML 入口及离线、只读边界。
